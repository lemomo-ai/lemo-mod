# lemo-mod 安全问题报告 · Security policy

[中文](#中文) · [English](#english)

## 中文

### 怎么报告

发现安全问题，请不要开公开 issue。在本仓库的 **Security** 页点 **Report a vulnerability** 私下提交（[直达链接](https://github.com/lemomo-ai/lemo-mod/security/advisories/new)）。写上版本号、在终端还是桌面 App 里出现、怎么复现。

### 哪些算安全问题

- 违反 [安全守则](SAFETY.md) 的行为：mod 替你放行或拦截工具调用、改了你的设置、在你的电脑上起程序、开关关着还在做事。
- 读出或泄露你的设置、对话、文件内容，或者把它们发到本机以外。
- 别人能借 mod 在你的电脑上运行命令。

外观问题和功能 bug 照常开 issue。

### 支持的版本

只修最新发布的版本。修好后发新版，在发布说明里写清楚修了什么。

## English

### How to report

Please don't open a public issue for a security problem. Report it privately: on this repo's **Security** page, click **Report a vulnerability** ([direct link](https://github.com/lemomo-ai/lemo-mod/security/advisories/new)). Include the version, whether it happens in the terminal or the desktop app, and how to reproduce it.

### What counts

- Anything that breaks the [safety rules](SAFETY.md): a mod that allows or blocks a tool call for you, changes your settings, starts a program on your computer, or acts while its switch is off.
- Reading or leaking your settings, conversations or files, or sending them off your computer.
- A way for someone else to run commands on your computer through a mod.

Open a normal issue for looks and feature bugs.

### Supported versions

Only the latest release gets fixes. A fix ships as a new release, and the release notes say what was fixed.
