What it is

lemo-mod 是什么What is lemo-mod

lemo-mod 是一组基于 Claude Code 官方 mod 接口的风格化 mod。装上之后，终端里的 Claude Code 和桌面 App 的 Code 标签都能一键换风格，配色、像素小画、加载词、音效和名字一起换。lemo-mod is a set of style mods built on Claude Code's official mod interface. Once installed, Claude Code in the terminal and in the desktop app's Code tab can switch styles in one click. Colors, pixel mascot, spinner words, sounds and names all change together.

除了外观，lemo-mod 还提供一整套功能，包括四页面板、用量横条、状态栏、音效、朗读、番茄钟、笔记、会话小结、抽签工具和一个只读助手。你的设置只读不改，外观以外的功能都由你自己开启。Beyond looks, lemo-mod provides a full set of features, including a four-page panel, a usage band, a status line, sounds, speech, a focus timer, notes, session recaps, a lot-drawing tool and a read-only assistant. Your settings are only read, never changed, and every feature beyond looks is yours to turn on.

Safety

安全Safety

mod 以你的权限运行，所以选择可信的 mod 很重要。lemo-mod 遵循以下原则。A mod runs with your permissions, so it matters whose mods you install. lemo-mod follows these rules.

读 SAFETY.mdRead SAFETY.md ↗
  1. 不替你做权限决定。No permission decisions for you.任何工具调用都不由 mod 放行或拦截，全按你自己的设置和权限模式。No mod allows or blocks a tool call. Your own settings and permission mode decide.
  2. 你的设置只读不改。Your settings are read, never changed.只读取和 mod 重叠的几项，只在本机读取，不保存，也不发给 Claude。Only the few that overlap with the mods are read, on your machine. They are not stored and not sent to Claude.
  3. 装上时只开外观。Only looks are on at install.其他功能默认关闭。Everything else starts off.
  4. 自动功能都在安全页有开关。Every automatic feature has a switch on the Safety page.手动功能只在你点按钮或输入命令时运行。输入 /lemo-mod 安全 打开安全页。On-demand features run only when you press a button or type a command. Type /lemo-mod safety to open the page.
  5. 和你的配置重叠时，以你的为准。Where your setup overlaps, yours wins.比如你设置了自己的状态栏或加载词，就继续用你的，安全页会写明原因。If you set your own status line or spinner words, yours stay, and the Safety page says why.

想在安装前自己检查，可以克隆本仓库并运行下面这行。输出中的 hooks: 和 calls: 两行列出每个 mod 接管哪些事件、请 Claude Code 做哪些事。To check before you install, clone the repo and run this. The hooks: and calls: lines in its output list the events each mod handles and what it asks Claude Code to do.

claude plugin validate plugins/<mod>
Install

安装Install

需要 Claude Code v2.1.287 或更高版本，可用 claude --version 查看。You need Claude Code v2.1.287 or later. Check with claude --version.

在终端运行：In your terminal, run:

claude plugin marketplace add lemomo-ai/lemo-mod
claude plugin install lemo-mod@lemo-mod
  • 装好后重开 Claude Code，终端或桌面 App 的 Code 标签都可以。面板会先显示安全页，打开想用的功能，再点「我看完了」。Then restart Claude Code, in the terminal or in the desktop app's Code tab. The panel starts on the Safety page. Turn on what you want and press I have read this.
  • 终端宽度不足 144 列时，输入 /lemo-mod 安全 打开。换风格用 /lemo-mod 风格 <名字>。In a terminal narrower than 144 columns, type /lemo-mod safety to open it. Switch styles with /lemo-mod style <name>.
  • lemo-mod 会装上全部 16 个 mod。每个 mod 都是独立插件，可以在 /plugin 里单独关闭。lemo-mod installs all 16 mods. Each one is its own plugin, so you can turn any of them off in /plugin.
  • 想要最好的效果，请让 Claude Code 的主题和终端本身的明暗保持一致，比如黑底终端配深色主题。主题用 /theme 设置。桌面 App 用浅色模式效果最好。For the best look, match Claude Code's theme to your terminal's light or dark background, for example a dark theme on a dark terminal. Set the theme with /theme. In the desktop app, light mode looks best.
